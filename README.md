# Портфолио Эдуарда

Одностраничный сайт-портфолио на чистых HTML, CSS и JavaScript. Откройте `index.html` в браузере или опубликуйте папку на GitHub Pages / любом статическом хостинге.

## Быстрая настройка

1. В начале `index.html` замените значения в блоке **«МОИ КОНТАКТЫ»**.
2. Замените `ЗДЕСЬ_БУДЕТ_ССЫЛКА_НА_СТО`, `ЗДЕСЬ_БУДЕТ_ССЫЛКА_НА_САЛОН` и `ЗДЕСЬ_БУДЕТ_ССЫЛКА_НА_ПРИГЛАСИТЕЛЬНЫЕ` на реальные ссылки.
3. Превью проектов находятся в `images/projects/`. Для фотографических скриншотов используйте оптимизированные WebP-файлы с именами `cont-modul.webp`, `sto.webp`, `beauty.webp`, `invitation.webp`, затем обновите расширение в четырёх `src` в HTML.
4. До публикации замените `https://eduard-portfolio.github.io/` в `index.html`, `robots.txt` и `sitemap.xml` на свой домен.

## Структура

```text
index.html          — контент и разметка
css/style.css       — стили и адаптивность
js/main.js          — меню, header и анимации появления
images/projects/    — превью работ
favicon/            — иконка сайта
robots.txt
sitemap.xml
```

Проект не использует внешние библиотеки и шрифты. SVG-превью — лёгкие редактируемые временные обложки; замените их реальными изображениями работ перед публикацией.
